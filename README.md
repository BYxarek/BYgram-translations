# Переводы BYgram

Здесь хранятся **только тексты интерфейса BYgram**. Исходный код приложения находится в отдельном приватном репозитории.

| Каталог | Содержание |
| --- | --- |
| [`locales/en`](locales/en) | Исходный английский текст |
| [`locales/ru`](locales/ru) | Русский перевод |
| [`locales/uk`](locales/uk) | Украинский перевод (может быть неполным) |

В каждом каталоге два Android XML-файла: `bygram_strings.xml` и `bygram_preferences.xml`. Отсутствующие переводы показываются на английском языке.

## Как предложить перевод

1. Создайте форк репозитория и измените нужный файл в `locales/<язык>/` через сайт GitHub или локальный редактор.
2. Сохраните имена ресурсов (`name`), номера аргументов (`%1$s`, `%2$d`), XML-теги и порядок элементов `<string-array>`.
3. Откройте pull request в ветку `main`. В описании укажите язык и какие фразы изменились. Мы проверим текст и XML перед слиянием.

Чтобы предложить новый язык, добавьте каталог с кодом языка Android (например, `locales/de`) и один или оба XML-файла. Можно переводить постепенно: отсутствующие строки останутся на английском.

Чтобы сообщить об ошибке без pull request, создайте [issue](https://github.com/BYxarek/BYgram-translations/issues) или напишите в поддержку BYgram. Укажите язык, текущую фразу, предложенный текст и экран приложения.

После слияния переводов сопровождающий импортирует проверенный коммит в закрытый репозиторий приложения. Публикация перевода здесь сама по себе не обновляет уже установленное приложение.

Материалы репозитория распространяются по [GNU GPL v2](LICENSE).
